# 步频（Bupin）

面向“尝试过跑步但当前低频”的新手跑者的交互 Demo。产品用“至少 10 分钟的真实跑走 + 按周目标”替代每日连续打卡，帮助用户建立允许恢复、可以持续的运动节奏。

> 当前阶段：可交互 Web Demo。核心规则与生产构建已验证，真实用户研究和 14 日行为验证尚未完成。

**在线体验：** [https://liu-joker669.github.io/bupin-app/](https://liu-joker669.github.io/bupin-app/)

建议先使用“模拟跑步（Demo）”体验完整闭环。真实 GPS 记录需要在支持定位的手机浏览器中授权位置权限，并尽量在室外使用。

## 核心闭环

`设定每周目标 → 完成一次跑走 → 判断是否为有效活动 → 查看本周进度 → 再次完成 → 达成周计划`

## 已实现

- 浏览器 GPS 定位、Haversine 距离计算、实时平均配速和 SVG 路线轨迹；
- GPS 获取中、弱信号、定位成功、权限拒绝和超时等状态反馈；定位等待时间不计入运动；
- 按定位精度动态确定采样距离，过滤弱信号和不合理速度跳点，并隔离暂停期间的位置跳变；
- 可加速体验的 Demo 跑走模式；
- 本周计划、同日去重、连续达成周数与每周目标快照；
- 日历、活动详情、一致性徽章和规则版“今日计划助手”；
- localStorage 数据持久化与旧数据迁移；
- 12 个核心规则自动化测试，包含 Demo 时间、距离、配速同步、路网坐标约束、GPS 点过滤与米制轨迹投影。
- 精细 Demo 示意地图：人物沿原有模拟路网行动，规划路线、运动轨迹和人物共享道路坐标，并提供人物跟随、状态气泡与缩放控件；不冒充真实地图服务。

## 数据口径

| 类型 | 定义 | 保存到历史 | 计入周计划 / 累计 / 徽章 |
|---|---|---:|---:|
| 有效活动 | 非 Demo 且时长 ≥10 分钟 | 是 | 是 |
| 短时记录 | 非 Demo 且时长 <10 分钟 | 是 | 否 |
| Demo 演示 | `isDemo=true` | 是 | 否 |

同一自然日有多次有效活动时，周计划只计 1 个计划日。用户修改周目标时，本周目标会更新，历史周继续使用已经保存的目标快照。

## 能力边界

- “今日计划助手”是本地规则，不是 LLM，也不提供医疗或专业训练建议；
- GPS 功能依赖浏览器权限和设备环境，当前不能声称定位精度已经过真机样本验证；
- 真实模式使用经纬度绘制相对轨迹示意，不是带道路信息的真实地图或专业后台定位服务；
- GPS 相对轨迹使用固定米制比例和动态比例尺，短距离不会被强行拉伸铺满画布；
- 没有真实分段配速时不生成随机曲线；
- 指标和埋点事件已设计，但尚未接入生产分析平台；
- “10 分钟能降低启动压力”仍是待验证假设，不是用户研究结论。

## 目录说明

```text
src/
├─ app-context.js       # React Context 读取入口
├─ domain/runs.js       # 活动资格、周目标、连续周、统计与徽章规则
├─ domain/gps.js        # GPS 精度阈值、轨迹采样、距离与错误文案
├─ store.jsx            # 状态迁移、持久化与 reducer
├─ components/          # 底部导航、规则版计划助手
├─ pages/               # 首页、跑走、日历、详情、徽章、个人页
└─ utils/format.js      # 时间、距离与配速格式化
tests/
└─ runs.test.js         # 资格、Demo 隔离、周计划、配速与 GPS 规则
```

## 关键版本变化

### v1.0 → v1.1

- 发现“默认每周 3 次”与“每日 streak”冲突；
- 改为按周计划连续达成；
- 将 AI 教练降级为明确标注的规则助手；
- 移除真实模式下的模拟心率和假路线。

### v1.1 → v1.2

- 建立唯一的有效活动资格规则；
- Demo 与短时记录不再污染周进度、累计数据和徽章；
- 增加每周目标快照，避免改写历史成绩；
- 修复实时配速单位；
- 删除随机生成的配速曲线；
- 清理全部静态检查警告并补充自动化规则测试。

### v1.2 → v1.3

- 将模糊的“正在生成路线”拆分为定位中、弱信号、单点成功和轨迹生成状态；
- 首个有效定位点到达后才开始运动计时；
- 基于定位精度和最小位移过滤 GPS 点，避免静止抖动持续累加距离；
- 暂停恢复后创建新轨迹段，避免暂停期间的位置跳变计入距离；
- 为权限拒绝、定位不可用和超时提供可执行的恢复提示。

### v1.3 → v1.4

- 根据首次手机实测，修复短距离路线自动铺满画布、横纵比例失真和固定假比例尺；
- 将真实模式改为固定米制比例的中性轨迹画布，与 Demo 示意地图明确区分；
- 将有效定位精度收紧至 40 米，并按定位精度动态过滤小幅漂移和不合理速度跳点；
- 为应用内置浏览器补充定位权限说明、复制体验链接和重新检测入口；
- 将中国大陆手机网络下更稳定的 GitHub Pages 调整为推荐体验入口。
